# KBDL-011-R13 Evidence Manifest

This package records the field-specific source model and complete Approved-authority audit. The reproducible entry points are `scripts/field_model_audit.py`, `scripts/run_source_model_controls.py`, and `scripts/documentation_validator.py`.

The `artifacts` directory contains the 5,389-row field registry, 317-row effective-record audit, 266-row authority audit, 137-row AR2 audit, source-integrity audits, VAL results, normative-preservation result, candidate status, and production summary. The `negative-tests` directory contains all 16 isolated control results and their aggregate summary.

R12 clause inventories are preserved at `../kbdl-011-r12/artifacts/verified-clause-inventory.csv` and `../kbdl-011-r12/artifacts/not-verified-clause-inventory.csv`. R13 does not execute the eleven unresolved clause-evidence methods.
