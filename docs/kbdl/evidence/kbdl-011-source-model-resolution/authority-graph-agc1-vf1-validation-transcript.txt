3. Root cause
--------------------------------------------------------------------------

scripts/validate_packet.py (pre-fix) computed the three
AG.narrow_authorized_diff.* checks from:

    subprocess.run(["git", "-C", REPO, "diff", "-U0", "HEAD", "--", <file>])

This is a working-tree-vs-symbolic-HEAD comparison. It was correct only
in the pre-commit state, when the working tree held the uncommitted
AGC1 correction against the *old* HEAD (46104c5). Once the correction
was committed (0fadb97) and the working tree became clean, `git diff
HEAD` is compared against the *new* HEAD -- which now already contains
the correction -- so the diff is empty:

  - AG.narrow_authorized_diff.csv_row_count_unchanged requires added==
    removed==2; an empty diff gives added=0 removed=0, so this FAILS.
  - AG.narrow_authorized_diff.readme_only_mot007_008 and
    .csv_only_mot007_008 both assert "no *other* KBDL-MOT-### line
    appears in the added/removed lines"; an empty list of added/removed
    lines trivially satisfies "contains no disallowed line," so both
    PASS -- but vacuously, since they are not actually inspecting the
    historical AGC1 diff at all once the tree is clean.

The validator therefore never inspected the actual, immutable AGC1
correction commit after publication; it inspected only whatever (if
anything) differed between the working tree and whatever ref HEAD
happened to point at, which drifts with every future commit.

5. Validator implementation change
--------------------------------------------------------------------------

Added scripts/agc1_narrow_diff.py, which:

  - Defines AGC1_BASE_SHA = "46104c57f86a924b197f6ed380a5b1127eddbf7d"
    and AGC1_TARGET_SHA = "0fadb9713299fb861830e419e06da8d82175ea1a" as
    explicit immutable commit-identity constants (never symbolic HEAD).
  - commit_exists(repo, sha): `git cat-file -e <sha>^{commit}` --
    fails closed if either commit is unresolvable.
  - verify_ancestry(repo, base, target): `git rev-parse <target>^` must
    equal exactly `base` -- fails closed on any other parent (not "some
    ancestor," the exact direct parent).
  - diff_added_removed(repo, base, target, path): `git diff -U0 --no-color
    <base> <target> -- <path>` using an explicit subprocess argument
    array (never shell interpolation); returns None on any nonzero git
    exit, which callers treat as a hard FAIL.
  - check_narrow_authorized_diff(...): orchestrates the above and
    returns the three checks, each requiring a *nonempty* diff in
    addition to the "no other MOT requirement touched" / "exactly 2
    rows changed" conditions, so an empty or unresolved range cannot
    pass any of them.

scripts/validate_packet.py now imports agc1_narrow_diff and replaces
its three inline `git diff -U0 HEAD -- <file>` blocks with a single call
to `agc1_narrow_diff.check_narrow_authorized_diff(REPO)`, which resolves
to the immutable range by default.

Added scripts/agc1_narrow_diff_fixtures.py: a regression suite that
builds disposable temporary Git repositories (via `git init` in
`tempfile.mkdtemp()`), commits synthetic base/target states, and asserts
expected/actual pass-or-reject outcomes for:

  1. a valid two-row AGC1-style committed change (expect: all PASS)
  2. an empty base-to-target diff, via an --allow-empty commit (expect: REJECT)
  3. a working-tree-only uncommitted change, target_sha == base_sha (expect: REJECT)
  4. a change to only one target CSV row (expect: REJECT)
  5. a change to an unrelated CSV requirement row (expect: REJECT)
  6a. an added CSV requirement row (expect: REJECT)
  6b. a deleted CSV requirement row (expect: REJECT)
  7. an unrelated MOT README change (expect: REJECT)
  8. a target commit with the wrong parent, via an orphan-branch decoy (expect: REJECT)
  9a/9b. a missing base or target commit, via a fabricated SHA (expect: REJECT)
  10. (mandatory) the valid historical range still passes after HEAD
      advances to a later child commit, proving HEAD-independence
      (expect: PASS both before and after HEAD advances, with HEAD != target)

All cases run against temporary repositories only; the script hashes
real-repository files before and after and asserts they are unchanged.
